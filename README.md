# nopCommerce Manual QA Testing

## Project overview
This project focuses on manual quality assurance testing of the nopCommerce e-commerce application.
The purpose of this project is to practice and demonstrate professional QA activities including test planning, test case design, test execution, defect reporting, retesting, and test reporting.

## Application under test
nopCommerce

## Testing approach
Manual Functional and Non-Functional Testing
