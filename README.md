# nopCommerce Manual QA Testing

## Project Overview
This project focuses on manual quality assurance testing of the nopCommerce e-commerce application.

The project demonstrates practical QA activities, including test planning, test case design, manual test execution, defect reporting.

## Application Under Test
nopCommerce

## Testing Approach
Manual Functional and Non-Functional Testing

## Tools & Technologies
- Jira
- Microsoft Excel
- GitHub
- Web Browser

## Project Scope

### 1. Functional Testing – Customer / Frontend Portal
- User Registration
- User Login
- Product Browsing and Searching
- Product Details
- Shopping Cart
- Checkout and Order Placement
- Customer Account
- Wishlist
- Customer Logout
- Forgot Password
- Footer Navigation

### 2. Non-Functional Testing
- Usability Testing
- Responsive Design Testing
- Browser Compatibility Testing
- Basic Performance Testing
- Basic Accessibility Testing

## QA Activities
- Test Planning
- Test Case Design
- Test Execution
- Defect Reporting
- Regression Testing

## Project Documentation
QA documentation, test cases, execution records, and project reports are maintained in GitHub.

## Project Status
**Completed**

Functional testing of the Customer / Frontend Portal and selected Non-Functional Testing activities have been completed.

**Note:** Administrator Portal testing was not included in this project scope.
